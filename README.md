### What I've built

**[chromebook-enrollment](https://github.com/dribeiro0/chromebook-enrollment)** · C++ · Arduino
An HID automation tool that enrolled **300+ Chromebooks in two days** and cut per-device setup time by roughly **70%**. Built for my school's IT department on a trimmed fork of Centipede — a manual process that didn't scale, replaced with one that did.

**[H4I-HeySam-Buildathon](https://github.com/dribeiro0/H4I-HeySam-Buildathon)** · HTML · JavaScript
A dashboard concept for **Hey Sam**, the peer-to-peer text support line run by Samaritans, built at the Samaritans × Hack4Impact BU Buildathon. Most marketing dashboards ask "did the campaign work?" This one asks "can we answer the next person who texts?" — ad spend is throttled against volunteer capacity, so growth can't outrun the people answering. Privacy is built into the data model: no message content, any group under 10 suppressed, nobody tracked from an ad to a conversation.

**[pi-game](https://github.com/dribeiro0/pi-game)** · Unity · C#
A solo Unity project carried across three versions, from 2D physics into 3D movement and multiplayer. The current build, Vertigo, focuses on grapple movement and tag.
